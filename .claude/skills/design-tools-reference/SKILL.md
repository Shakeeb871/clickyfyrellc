# Design Tools Reference

A lookup skill for finding the right tool, app or plugin for a design job.

- `references/tools.md`: 598 design tools in 36 categories, each with its link, what it does, and tags (Free, Open source, Mac, Web).
- `references/plugins.md`: 1064 plugins for Figma, Sketch and Adobe XD in 45 categories.

Both files start with a category list. Read the category list first, then read only the category you need. Do not load the whole file.

## The list is old: verify before recommending

The source list was last updated in September 2020. Many tools have since shut down, been renamed, been bought, changed their prices or dropped their free plan. So:

1. Shortlist 3 to 5 candidates from the catalog.
2. **Check each one is still alive** with a quick web search or by opening its link. Drop anything dead, shut down or abandoned.
3. **Check today's price and free plan** on the official site. Never repeat the old "Free" tag without checking it.
4. If the shortlist is thin after checking, search the web for current alternatives in the same category and say they did not come from this catalog.
5. Never present a 2020 detail as current fact.

## How to recommend

- Give each recommended tool with its **official website link**, one line on what it does, and whether it is free, freemium or paid as of today.
- Fit the pick to the person's setup: web or desktop, Mac or Windows, and which design app they use.
- Prefer Figma plugins over Sketch and Adobe XD plugins unless the user works in Sketch or XD. Adobe stopped active development of XD, so treat XD plugins as legacy.
- Lead with the best fit, not the longest list. Two or three solid options beat ten untested ones.
- Mention when a tool is open source, since it can be self-hosted or kept long term.

## Common needs and where to look

| Need | Category in tools.md |
|---|---|
| Check colour contrast and accessibility of a page | Accessibility Tools |
| Pick or build a colour palette | Color Picker Tools, Gradient Tools |
| Find or pair fonts | Font Tools |
| Icons and illustrations for a site | Icons Tools, Illustrations |
| Free stock photos and videos | Stock Photos Tools, Stock Videos |
| Device and screen mockups for client presentations | Mockup Tools |
| Wireframes, user flows and sitemaps | Wireframing Tools, User Flow Tools, Information Architecture |
| Clickable prototypes | Prototyping Tools |
| Hand designs to developers, or turn designs into code | Design Handoff Tools, Design to Code Tools |
| Build a site without code | No Code Tools |
| Website screenshots and annotated captures | Screenshot Software |
| Logo ideas | Logo Design |
| Design inspiration and reference galleries | Design Inspiration |
| Collect feedback or run user tests | Design Feedback Tools, User Research Tools, Experience Monitoring |
| Simple web animations and motion | Animation Tools |

For anything done inside Figma (export, align, data fill, charts, accessibility checks), look in `references/plugins.md`.
